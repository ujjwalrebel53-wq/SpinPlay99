Setup (nano nahi — sirf ye commands):

  cd www
  bash setup.sh

  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt
  playwright install chromium
  python bot.py

Seedha token + chat id dena ho to:

  bash setup.sh "BOT_TOKEN_YAHAN" "CHAT_ID_YAHAN"
