# NDA Prep Academy

UPSC NDA/NA Written Exam preparation website — practice questions, mock tests, syllabus, study plan, and progress tracking.

## Features

- **Dashboard** — Exam pattern, countdown, quick stats
- **Complete Syllabus** — Mathematics & GAT (English, Physics, Chemistry, History, Geography, Polity)
- **90-Day Study Plan** — 60/90/120 day structured plans
- **Practice Mode** — Topic-wise MCQs with instant explanations
- **Mock Tests** — Timed Math, GAT, and Combined mini mocks with negative marking
- **Formula Sheet** — Quick revision for Math & Science
- **Tips & Strategy** — Exam strategy in Hindi/English
- **Progress Tracking** — Subject-wise performance, weak areas, streak (saved in browser)

## How to Run

Open `index.html` in any browser, or serve locally:

```bash
cd nda-prep
python3 -m http.server 8080
```

Then visit: http://localhost:8080

## Tech Stack

Pure HTML, CSS, and JavaScript — no build step, no dependencies. Works offline after first load.
